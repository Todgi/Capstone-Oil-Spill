SAR Image Processing

U-Net Model
SAR (Synthetic Aperture Radar) Processing:
Uses deep learning U-Net model for pixel-wise oil spill segmentation from SAR imagery. Supports GeoTIFF format with radar data.

Optical Image Processing

MADOS Model
Optical/Multispectral Processing:
Uses MADOS (Marine Oil Spill Detection System) with MariNeXt model for oil spill detection from optical/multispectral imagery. Supports Sentinel-2 and similar data.
Input 11 band Sentinel-2 (B01.tif, B02.tif, B03.tif, B04.tif, B05.tif, B06.tif, B07.tif, B08.tif, B8A.tif, B11.tif, B12.tif) or ZIP containing 11 band files.
Band file names must match MADOS reference order.
